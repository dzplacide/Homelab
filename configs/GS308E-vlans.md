# Netgear GS308E — VLAN 802.1Q

[← Retour au homelab](../README.md)

Le GS308E se configure par son interface web : **VLAN › 802.1Q › Advanced › VLAN Membership** pour les membres (T = étiqueté, U = non étiqueté), puis **Port PVID** pour le VLAN par défaut de chaque port d'accès.
